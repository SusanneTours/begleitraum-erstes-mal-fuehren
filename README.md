# Begleitraum: Das erste Mal führen

Begleitraum für das zweitägige Haufe-Training von Susanne Tours.
Die Seite ist `index.html` (wird aus `src/` gebaut: `python3 src/build.py`). Fotos liegen in `bilder/`, Folien in `folien/`.
Fotos aus dem Training kommen in `fotos/` und werden in `src/app.js` unter `ERGEBNISSE` eingetragen.
